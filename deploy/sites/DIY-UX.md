# 分站 DIY：非技术站长的编辑器设计

> 起因（2026-10-24 祥哥）：**「这套 DIY 感觉不太实用，站长也是不动代码的小白，
> 他只是根据自己的喜好，在哪些位置放置哪些菜单，可以自定义文字、字体大小、
> 颜色、背景色，甚至可以上传自定义图片。」**
>
> 这一条很关键：我们已经把**能力**做齐了（6 模板 × 6 色系 × 4 首屏版式 × 3 服务版式
> × 圆角/密度/字体/按钮形状 × 模块开关与排序 × 逐块标题文案 × 自定义 CSS × 背景图），
> 但入口长成了一张**后台大表单**。站长不会用，等于没有。

---

## 一、参考产品怎么做的（2026-10-24 调研）

| 产品 | 关键做法 | 链接 |
|---|---|---|
| **Carrd** | 画布（Canvas）就是页面本身；点哪个元素，右侧弹属性面板；拖拽移动（有绿色指示条）；背景可选纯色/渐变/图片/视频/幻灯片；撤销/重做；手机视图单独预览 | [Basics](https://carrd.com/docs/building/basics) / [Overview](https://carrd.com/docs/building/overview) / [Background](https://carrd.com/docs/building/background-element) |
| **Shopify 主题编辑器** | 区块（section）列表 + 拖拽排序 + 每个区块自己的设置项；「添加区块」而不是「填字段」 | （官方文档需登录，抓到 403，按公开资料归纳） |
| **Squarespace Fluid Engine** | 栅格拖拽，所见即所得，强调"不用懂网格也能拖出好看版式" | [Engineering blog](https://engineering.squarespace.com/blog/2022/developing-fluid-engine) |
| **SMM 白标子面板**（同行） | 大多数只给「Logo + 主色 + 站点名」，属于最低配；没有区块级自定义 | [SMM Matrix Child Panel](https://codecanyon.net/item/smm-matrix-child-panel-addon-build-whitelabel-smm-panels/64824435) |

**结论：同行（SMM 子面板）几乎都不做 DIY，只换 Logo 和主色。**
这正是我们的机会 —— 但要赢，靠的不是"能配多少项"，而是**配起来有多轻松**。

## 二、从这些产品里提炼的 8 条原则

1. **画布优先**：站长打开就看到自己的站，不是一堆输入框。改的是"画布上的东西"。
2. **点哪改哪**：点标题改标题、点图片换图片。不要让他记"这个字段叫 hero_title"。
3. **先给成品，再给微调**：一进来先推荐 3~6 套**配色+版式打包**的方案，点一下整套生效。
   小白需要的是"选一个好看的"，不是"从零配"。
4. **控件不超过三类**：位置（上移/下移/隐藏）、文字（点开就改）、外观（颜色/字号/背景图）。
5. **不出现技术词汇**：没有 HEX、没有 px、没有 class 名。
   字号写「小 / 标准 / 大 / 特大」，圆角写「方 / 微圆 / 全圆」，颜色给色块点选。
6. **永远可撤回**：「撤销」「恢复默认」必须一直在。小白最怕"点坏了回不去"。
7. **手机单独看**：一半以上客户用手机，编辑器必须能切到手机宽度预览。
8. **一屏能看完**：把所有设置塞进一页会让小白直接放弃；用步骤（1 风格 → 2 颜色 → 3 文字）。

## 三、我们要做的（分三个阶段）

### P1 · 首页可视化编辑（本轮开始）
- 站长登录自己分站时，右下角出现「✏️ 编辑我的店」。
- 进入编辑态后：
  - 每个区块右上角出现 `↑ ↓ 🙈` 三个按钮（上移 / 下移 / 隐藏），**直接改首页顺序**
  - 区块标题（含副标题）可以**点击直接改**，回车保存
  - 底部工具条：`保存` / `放弃` / `恢复默认`
- 数据仍然写进现有的 `home_modules` 与 `section_titles`，**不新增表结构**。

### P2 · 外观三板斧（下一步）
- `样式` 抽屉，只有三组：
  1. **主色**：12 个色块（点一下整站变色，含按钮/价格/图表）
  2. **背景**：纯色（色块）/ 渐变（3 套预设）/ 上传图片（自动压缩裁剪）
  3. **字号与圆角**：小-标准-大；方-微圆-全圆
- 每组下面一行小字：「推荐：深色背景 + 亮主色，最显专业」这类**带方向的建议**，
  而不是干巴巴的选项（小白需要被引导，不需要被穷举）。

### P3 · 模板级预览（再下一步）
- 6 套模板给**缩略图**（不是文字列表），点一下整站换骨架。
- 换模板是**最大的一步**，必须能一眼看到效果 → 也就必须做"点击前预览"。

## 四、明确不做

| 不做 | 原因 |
|---|---|
| 自由拖拽像素定位 | 小白拖出来一定是灾难；栅格化排序（上下移）已经够 |
| 自定义 HTML/JS | 已有 `custom_css` 足够；JS 会带来 XSS 与合规风险 |
| 无限级字体/字号 | 选项越多越难选；给 4 档就够 |
| 让站长调"每屏间距 px" | 用「紧凑/标准/宽松」三档表达即可（已有 ui_density）|

---

## 五、验收标准（给祥哥看）

1. 不懂代码的人，**60 秒内**能把首页两个区块换个顺序、改掉一句标题、存上。→ 不达标就重做。
2. 全程**不出现**十六进制色值、像素、代码、英文术语。
3. 任何一步都能**一键撤回**。
4. 手机上看，编辑器不能把页面挤坏。
