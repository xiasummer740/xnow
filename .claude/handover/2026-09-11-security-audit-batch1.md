## 踩坑记录（都是真金白银换的）

1. **harness 第一次是"假通过"**：用 `fetch` 发请求时 **undici 把 `Host` 当禁用头静默丢弃**，导致"伪造 Host"那条用例其实 Host 一直是本地地址，等于没测。**必须用 `node:http` 才能设 Host。**
2. **给鉴权中间件加失败分支前，先看前端拿到那个状态码会做什么**：我第一版把所有异常都当"登录失效"回 401，而 `main.ts:24` 收到 401 会 `logout()+alert()+跳登录页` → MySQL 抖一次＝**全体在线用户被踢下线**。现已拆分 401/503。
3. **默认值只能用于"缺省"，绝不能用于"兜住非法输入"**：我用 `isFinite(d) && d > 0 ? d : 默认值` 兜非法折扣 → 校验通过、落库 NaN。
4. **写"组合校验"要回到消费侧把每条分支都列出来**：定价护栏只验 `倍率×折扣`，漏了"普通用户不乘折扣"这条分支，被 `倍率0.05+折扣100` 绕过。
5. **WAF 黑名单有 30 秒缓存**，测中途改环境变量不生效。

## ⚠️ 最重的一条（也是卡住部署的原因）

复审实测 + 我复核确认：**生产站挂在 Cloudflare 后面**（`Server: cloudflare` + `CF-RAY`），而源站 nginx **没配 `real_ip`**。链路为 客户端 → CF 边缘 → nginx（`$remote_addr` = CF 边缘 IP）→ 追加到 XFF 最右段 → `trust proxy=1` 下 **`req.ip` = CF 边缘 IP**。

后果：WAF 黑名单永不命中（拉黑无效、无日志）、照用户列表的 IP 拉黑会**误封整片用户**、`register_ip`/`last_login_ip`/`/geo/:ip` 全是 CF 机房地址、`authLimiter`（30 次/15 分）变成"整条边缘共享配额"。

**这条同时让第一批的 WAF 修复在生产失效** —— 代码方向对（取最右段），但生产的最右段现在是错的值。
