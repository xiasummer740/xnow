## 四、三个必须记住的坑

### 坑 1：`client/dist/index.html` 是构建产物，`git checkout` 会把它回退

线上首页一度指回旧 bundle（不白屏、不报错，只是你看到的是上一次的界面）。
已 `git rm --cached`，以后 **dist 只能由本地 build + 上传决定**。
验证方法：
```bash
grep -o "index-[A-Za-z0-9_-]*\.js" client/dist/index.html   # 磁盘
curl -s https://<域名>/ | grep -o "index-[A-Za-z0-9_-]*\.js"  # 线上，两个必须一致
```

### 坑 2：新站证书必须"先立 vhost 再签证书"

certbot HTTP-01 校验时，如果 nginx 里还没有这个域名的 server 块，请求会落到默认站点 → 404 →
只能退回自签（浏览器警告）。建站流程现在是：
`ensureSelfSignedCert` → `writeVhost` → reload → `ensureCert` → `writeVhost(正式证书)` → reload。
**改 `server/src/routes/sites.js` 的 create 流程时不要把这个顺序调回去。**

### 坑 3：表格行上的按钮必须 `.stop`

用户表整行绑了打开详情的 click，操作按钮不写 `.stop` 就会连带弹详情窗 ——
表现是"关掉操作弹窗后自动跳出详情"，看起来像另一个 bug。
同理，任何"整行可点 + 行内有按钮"的表格都要检查这一点。
